# Data

The data are not included in this repository.

The data come from the MIDUS 3 Biomarker Project (ICPSR 38837): https://doi.org/10.3886/ICPSR38837.v1

Download the R version of the data from ICPSR and put the file here:

- `38837-0001-Data.rda` (creates the object `da38837.0001` in R)

Please read the ICPSR terms of use before using the data.
